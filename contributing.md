# Contribution Guidelines

## What belongs here

- A public tool for everyday student life in the Philippines: campus navigation, housing, student services, grades, transport, organizations, or orientation.
- A working project with a clear Philippine student audience.
- A description that says what students can do with it.

## What does not belong

- Generic learning platforms, tutoring sites, or courseware; use [Awesome PH EdTech](https://github.com/smmariquit/awesome-ph-edtech) for those.
- Landing pages with no usable product.
- AI-generated link dumps.

## Pull request checklist

- [ ] Link works.
- [ ] Description explains the student task it supports.
- [ ] Entry is in the right section and alphabetical order.
- [ ] No duplicate already exists.

## Description style

Bad:

> An innovative platform changing the campus experience.

Good:

> UPLB room finder with class schedules, building details, directions, and offline support.
